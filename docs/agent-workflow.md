# Agent 操作约定

本项目以原生 NanoKVM MCP + SSH 工作，确定脚本负责按键，Agent 检查检查点与例外，不使用旧 gateway。

- BIOS 路径、单位、下拉和存档槽必须对实际设备校准；不猜偏移，不把上次光标作为锚点。
- 进入 BIOS 用 Delete，目标 250ms，容忍 POST 短暂 HID 错误。没有 POST 总超时，黑屏不自动 reset/reboot。
- 只有明确授权、实际校准根页才自动运行固定宏；F10 必须停在确认前。Agent 检查全部清单与 Profile8 保存/名称证据；额外变更或缺页拒绝。审批绑定请求/profile/图片 SHA，发 Enter 只消费一次。
- Profile8 普通覆盖保留既有 agent-tune 名称；首次命名或修复单独审核。存档槽不是候选数组的 slot。
- 开机/F10 前通过 DSView CLI/IPC 请求采样，桌面确认后停止排空。DSView 不作任何 BIOS/POST/电压/测试决定；不等样本增长，不强杀活动 recorder。
- 先采唯一 AFU `/O` dump 和完整 ZenTimings CLI JSON，复用现有 HWiNFO/SM2，启动 HWTrace，接收/hash/精确读回/新 sample 验证后才测试。不闪写、不恢复、不额外写寄存器。
- VT3 十次独立启动，各最多 600s，启动至退出计时与间隔分开，算法错误继续剩余轮次。十日志及汇总传输校验完才通知。
- 密钥和密码留在认证环境，不读凭据目录、不写源码/日志/manifest。保留原始证据和活动负载。
- 新代码用离线 fake；离线测试、只读连通性、真实校准、完整实验分别报告。短测无错不是稳定。

公开 profile 的历史校准不是当前机器状态或执行授权。具体范围由操作者按本次硬件与实验另行提供；本地扫描队列不自动分发。
